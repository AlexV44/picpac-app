# PicPac — мобильное приложение для заказа фотокниг

Мобильное веб-приложение (PWA) для picPac.by: клиент загружает фото, ИИ собирает из них альбом, дальше корзина, оформление и отслеживание заказа. Для бизнеса есть панель администратора с гибким каталогом.

**Как установить на телефон**
- **Android (Chrome):** ссылка → ⋮ → Установить приложение → Установить
- **iPhone (Safari):** ссылка → Поделиться → На экран «Домой» → Добавить

**Тестовые аккаунты** (данные синтетические)

| Роль | Логин | Пароль |
|---|---|---|
| Гость | кнопка «Продолжить как гость» | — |
| Клиент | `client@picpac.test` | `client123` |
| Клиент с персональными предложениями | `vip@picpac.test` | `vip123` |
| Администратор | `admin@picpac.test` | `admin123` |

Промокод для проверки: `PICPAC10`. В демо статусы заказа идут сами, а кнопка «Демо: следующий статус» перематывает их сразу.

## Что умеет приложение

**Путь клиента (п. 6.2):** вход → каталог → выбор товара и параметров → загрузка фото → ИИ собирает альбом → корзина → оформление (доставка, оплата, промокод) → заказ с трек-кодом → статусы → история заказов.

**Мобильные функции (п. 6.3):**
- вход как гость или по аккаунту, две роли с разными правами;
- каталог и цены приходят через API (mock API), а не зашиты в интерфейс;
- загрузка фото с проверкой формата и качества, предупреждения перед заказом;
- заказ со статусами и push-уведомлениями (имитация);
- чат поддержки, привязанный к заказу;
- работа без сети: фото ставятся в очередь и догружаются, когда связь вернётся;
- удаление своих данных и фото в один тап;
- двуязычный интерфейс (русский и английский).

**Что выделяет проект:**
- **Умный альбом:** ИИ сам оценивает снимки, выбирает лучшие, кадрирует по лицам и расставляет по шаблону разворотов.
- **«Магия» для фото:** правки по просьбе, например «сделай в стиле Хэллоуин», «ярче», «убери лишнее». Всегда видно «Было / Стало», оригинал можно вернуть.
- **Робот-помощник:** отвечает по альбому и заказу, показывает ход мыслей.
- **Персональные предложения из CRM:** скидка ко дню рождения, «Мы скучаем», бесплатная доставка. У каждого предложения есть понятная причина.
- **Гибкая админка:** можно добавлять, менять и отключать товары, форматы, доставку, оплату и промокоды, смотреть воронку и заказы. Любое изменение записывается в журнал, а исходный каталог можно вернуть одной кнопкой.
- **Мягкая замена товара:** если админ убрал то, что клиент уже выбрал, клиент видит понятное сообщение с причиной и предложением заменить товар или его параметр.
- **Ссылки на экраны (deep links):** например, на историю заказов или на конкретный проект.

## Какие модели используются и для чего

| Модель | Для чего | Где работает |
|---|---|---|
| **YuNet** (OpenCV Zoo, MIT) | Находит лица на фото, чтобы кадрирование не отрезало людей | Локально, без интернета |
| **Haar-каскад** (OpenCV) | Запасной вариант поиска лиц, если YuNet недоступна | Локально |
| **Оценка качества** (резкость, свет, разрешение для печати) | Предупреждает, что фото получится нечётким, и подсказывает замену. Это расчёт, а не нейросеть | Локально |
| **Real-ESRGAN** `realesr-general-x4v3` (необязательно) | Повышает разрешение слабых по размеру фото перед печатью | Локально |
| **GLM-5.3 Flash** (`z-ai/glm-5.3-flash`) | Текстовый помощник: отвечает на вопросы, предлагает правки | Через OpenRouter, по ключу |
| **GPT-OSS 20B** (`openai/gpt-oss-20b`) | Запасная модель помощника, если первая недоступна | Через OpenRouter, по ключу |

**Приватность.** В текстовую модель уходит только структура альбома и оценки качества, сами фото не уходят. Правки «Магия» выполняются локально, без генерации картинок нейросетью. Без ключа OpenRouter всё работает локально, помощник отвечает по заготовленным сценариям. Фото авторизованного пользователя хранятся в базе, фото гостя хранятся во временном кэше 24 часа, при входе в аккаунт они переносятся в базу. Пользователь может удалить свои данные в любой момент.
