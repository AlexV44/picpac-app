# Сценарий демонстрации (5–7 минут)

Запуск: `pip install -r requirements.txt && python server.py`, открыть `http://localhost:8000/` (на ноутбуке откроется рамка телефона).

1. **Вход (0:30).** «Продолжить как гость». Показать, что вход тестовой записью тоже есть (клиент `client@picpac.test` / `client123`).
2. **Каталог (0:45).** Главная: 5 услуг с ценами, карточка Premium: срок изготовления и требования к фото, выбор обложки.
3. **Проект (1:30).** «Выбрать фото» → «Демо-фото» (или загрузить свои JPEG/PNG). Показать порядок фото (карточка фото → «Раньше / Позже») и предупреждение о качестве.
4. **Альбом (1:30).** «Собрать альбом», правка кадра, нажатие на фото → «Спросить у ИИ про это фото» → «сделай в стиле Хэллоуин»: ход мыслей в чате, результат «Было / Стало».
5. **Корзина (0:45).** «Заказ» → позиция в корзине, добавить вторую услугу (Фотопечать), изменить количество.
6. **Оформление (1:00).** Доставка, контакты, промокод `PICPAC10` (цена пересчитывается), проверка перед печатью; кнопка заказа закреплена внизу.
7. **Трекинг (0:45).** Трек-код, 9 статусов в 5 группах, «Демо: следующий статус», push-баннер при смене.
8. **Поддержка (0:45).** ⚙ → «Чат поддержки» или кнопка на экране заказа: автоответ со статусом заказа; «Хочу оператора» → ответ оператора.
9. **Роли (0:45).** ⚙ → «Войти» → `admin@picpac.test` / `admin123` → главным экраном становится панель администратора (вкладки «Сводка», «Заказы», «Обращения», «Журнал»): KPI, поиск и смена статуса, ответы клиентам, журнал операций. Клиент туда не попадёт: сервер отвечает 403.
10. **Данные (0:15).** ⚙ → «Удалить мои данные».

Проверка ошибок: выключить сеть (DevTools → Offline): появится красная полоса, форма заказа сохраняется, повторная отправка не создаёт второй заказ.


## Сценарий «персональные предложения из CRM»
1. Войти как `vip@picpac.test` / `vip123`: на главной блок «Для вас» (день рождения −20%, личная скидка, бесплатная доставка), у каждой карточки есть причина.
2. Собрать альбом (кнопка демо-фото), дойти до оформления: карточка «Для вас», строка «Скидка ко дню рождения», доставка бесплатна. Кнопка «Не применять» возвращает обычную цену.
3. Войти как `sleep@picpac.test` / `sleep123`: предложение «Мы скучаем» (−12%) и совет собрать фотокнигу.
4. Войти как гость: персональных предложений нет.
5. Администратор: «Сводка» → «Интеграция с CRM» (режим, связь, запросы).
