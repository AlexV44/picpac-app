# Отчёт о тестировании (трек 2)

Команда: `python selftest.py`: без браузера и без ключей, данные во временной папке, OpenRouter подменён локальным заглушечным сервером.
Дополнительно: сквозной сценарий в браузере на эмуляции телефона 390×800 (Playwright/Chromium): вход гостем, демо-фото, порядок фото, корзина,
промокод, оформление, трекинг, поддержка, вход админа. Ошибок консоли и необработанных исключений нет; эмодзи в интерфейсе не осталось.

| МП-02 JPEG/PNG и лимиты | GIF, слишком маленькое фото, файл >25 МБ отклоняются понятным текстом; PNG принят | пройдено |

## Что не проверено

- Живые запросы к OpenRouter (чат и правка фото): проверены только на заглушке.
- ИИ-апскейл Real-ESRGAN (нужны torch и веса).
- Реальный телефон и установка на экран «Домой» (нужен HTTPS).
- Системные push-уведомления: в приложении имитируются баннером, системные работают только после разрешения и пока вкладка открыта.
